## 📋 问题背景

**原问题** (v2.2.2发现):
- Topic和Script API响应包含JSON控制字符
- jq工具无法解析响应：`jq: parse error: Invalid string: control characters from U+0000 through U+001F must be escaped`
- 影响测试脚本和工具链自动化

**优先级**: P2  
**影响范围**: 工具链兼容性（不影响业务功能）

---

## 🛠️ 修复方案

### 问题根因分析

控制字符在AI生成阶段产生，然后：
1. 存储到数据库（未清理）
2. 通过API返回（未清理）
3. jq工具解析时报错

### 修复策略：双重清理

#### 1. 数据库存储层清理（治本）

**`server/db/repositories/topic.repo.ts`**
```typescript
// 添加清理函数
function cleanControlChars(str: string): string {
  return str.replace(/[\u0000-\u0008\u000B\u000C\u000E-\u001F\u007F-\u009F]/g, '')
}

// 在 create() 函数中应用
const title = cleanControlChars(data.name || data.title || '')
const angle = cleanControlChars(data.direction || data.angle || '')
const persona = cleanControlChars(data.targetPersona || data.persona || '')
const cta = cleanControlChars(data.cta || data.core || '')
// ... 所有字符串字段
```

**`server/db/repositories/script.repo.ts`**
```typescript
// 同样的清理函数
function cleanControlChars(str: string): string {
  return str.replace(/[\u0000-\u0008\u000B\u000C\u000E-\u001F\u007F-\u009F]/g, '')
}

// 在 create() 函数中清理
const fullText = cleanControlChars(data.fullVoiceover || data.fullText || '')
const cleanedSegments = (data.segments || []).map(seg => ({
  ...seg,
  content: seg.content ? cleanControlChars(seg.content) : seg.content,
  voiceover: seg.voiceover ? cleanControlChars(seg.voiceover) : seg.voiceover,
  // ... 所有字符串字段
}))
```

```typescript
const parsed = topics.map(t => ({
```

```typescript
  type: seg.type,

  // ...

```

### 清理规则

**移除的控制字符**:
- U+0000-U+0008: NUL到BS
- U+000B-U+000C: VT和FF
- U+000E-U+001F: SO到US
- U+007F-U+009F: DEL和C1控制字符

**保留的字符**:
- U+0009 (\t): 制表符
- U+000A (\n): 换行符
- U+000D (\r): 回车符

这些字符在JSON字符串中是合法的。

```python
with open('topic-response.json', 'r') as f:
    content = f.read()

# 查找控制字符
control_chars = []
for i, char in enumerate(content):
    code = ord(char)
    if (0x00 <= code <= 0x08) or (0x0B <= code <= 0x0C) or \
       (0x0E <= code <= 0x1F) or (0x7F <= code <= 0x9F):
```
