## 📋 功能概述

PDF导出功能使用 **jsPDF + html2canvas** 在浏览器端生成PDF文件：
- **纯前端实现**：无需后端服务，在浏览器中完成PDF生成
- **A4格式**：210mm × 297mm，适合打印
- **深色主题**：背景#0D0D0D，文字#FFFFFF
- **自动分页**：内容超过一页时自动分页
- **JPEG压缩**：图片质量0.8，文件大小适中

## 🐛 常见问题排查

### 问题1: 点击按钮无反应

**可能原因**:
- reportHtml为空（未生成报告）
- JavaScript错误

**排查方法**:
1. 打开浏览器开发者工具（F12）
2. 查看Console是否有错误
3. 确认reportHtml已生成（在React DevTools中检查）

### 问题2: 生成时间过长（>10秒）

**可能原因**:
- 报告HTML内容过大
- html2canvas渲染慢

**排查方法**:
1. 检查报告HTML的大小
2. 尝试降低scale参数（在`pdf-export.ts`中）
3. 检查浏览器性能（CPU使用率）

### 问题3: PDF文件损坏或无法打开

**可能原因**:
- jsPDF生成过程出错
- 文件下载不完整

**排查方法**:
1. 检查Console是否有错误
2. 尝试重新生成
3. 检查文件大小是否异常（如0KB）

### 问题4: PDF内容不完整

**可能原因**:
- 分页逻辑错误
- html2canvas渲染不完整

**排查方法**:
1. 检查reportHtml是否完整
2. 在`pdf-export.ts`中增加日志，查看canvas高度
3. 检查分页逻辑（heightLeft计算）

### 问题5: 中文显示乱码

**可能原因**:
- jsPDF默认字体不支持中文（不太可能，jsPDF v3+支持Unicode）

**解决方法**:
- 检查jsPDF版本（应该>=3.0）
- 如果仍有问题，需要引入中文字体文件

## 🔍 技术细节

### pdf-export.ts 关键参数

```typescript
// html2canvas配置
{
  scale: 1.5,           // 清晰度（2.0更清晰但文件更大）
  useCORS: true,        // 允许跨域图片
  backgroundColor: '#0D0D0D',  // 深色背景
  logging: false,       // 关闭日志
}

// jsPDF配置
{
  orientation: 'portrait',  // 纵向
  unit: 'mm',              // 单位：毫米
  format: 'a4',            // A4格式
  compress: true           // 压缩
}

// 图片配置
canvas.toDataURL('image/jpeg', 0.8)  // JPEG格式，质量0.8
```

### 分页算法

```typescript
const pageHeight = 297        // A4高度（mm）
let heightLeft = imgHeight    // 剩余高度
let position = 0              // 当前位置

// 添加第一页
pdf.addImage(imgData, 'JPEG', 0, position, imgWidth, imgHeight)
heightLeft -= pageHeight

// 添加后续页面
while (heightLeft > 0) {
  position = heightLeft - imgHeight
  pdf.addPage()
  pdf.addImage(imgData, 'JPEG', 0, position, imgWidth, imgHeight)
  heightLeft -= pageHeight
}
```
