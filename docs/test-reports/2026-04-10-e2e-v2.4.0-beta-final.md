## 🐛 Bug修复记录

### Bug #1: PPT导出substring错误（已修复）✅

**发现时间**: 2026-04-10 04:42  
**错误信息**: `Cannot read properties of undefined (reading 'substring')`

**根本原因**:
- `server/services/report/ppt-generator.ts` Line 361
- 洞察内容字段（insight.content）未做空值检查
- 当content为null或undefined时，调用substring方法导致运行时错误

**修复方案**:
```typescript
// 修复前
const content = insight.content.substring(0, 150) + (insight.content.length > 150 ? '...' : '')

// 修复后
const content = insight.content
  ? (insight.content.substring(0, 150) + (insight.content.length > 150 ? '...' : ''))
  : '-'
```

**修复时间**: 2026-04-10 04:54  
**验证结果**: ✅ 所有模板测试通过（4/4）  
**影响范围**: v2.4.0-beta PPT导出功能
