## 🚀 5分钟快速部署

### 前置准备

**必需**:
- ✅ Node.js >= 18
- ✅ Claude API Key
- ✅ 5分钟时间

### Step 1: 配置环境变量（1分钟）

```bash
# 复制环境变量模板
cp .env.example .env
```

编辑 `.env` 文件，填入你的API Key：
```env

PORT=3001
```

### Step 2: 启动应用（2分钟）

```bash

# 启动开发服务器
npm run dev
```

### Step 3: 验证部署（1分钟）

打开浏览器访问：
- **前端**: http://localhost:5177
- **后端**: http://localhost:3001/api/health

看到应用界面 → ✅ 部署成功！

## 🔧 完整部署流程

### 生产环境部署

#### 选项1：Railway部署（推荐，最简单）

```bash
# 1. 注册Railway账号
# 访问：https://railway.app

# 2. 安装Railway CLI
npm install -g @railway/cli

# 3. 登录
railway login

# 4. 部署项目
railway init
railway up

# 5. 设置环境变量
railway variables set ANTHROPIC_API_KEY=sk-ant-your-key

# 6. 获取部署URL
railway domain
```

**完成！** 你会得到一个公网可访问的URL。

#### 选项2：Render部署

1. 访问 [render.com](https://render.com)
2. 连接GitHub仓库
3. 选择"Web Service"
4. 配置：
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
5. 设置环境变量：`ANTHROPIC_API_KEY`
6. 点击"Deploy"

#### 选项3：Docker部署

```bash
# 1. 构建镜像
docker build -t super-insight .

# 2. 运行容器
docker run -p 3001:3001 \
  -e ANTHROPIC_API_KEY=sk-ant-your-key \
  super-insight

# 3. 访问应用
open http://localhost:3001
```

#### 选项4：服务器部署（VPS/云服务器）

```bash
# 1. 连接服务器
ssh user@your-server.com

# 2. 安装Node.js（如果还没有）
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 3. 克隆项目
git clone your-repo-url
cd super-insight

# 4. 安装依赖
npm install

# 5. 配置环境变量
nano .env
# 填入：ANTHROPIC_API_KEY=sk-ant-your-key

# 6. 构建生产版本
npm run build

# 7. 使用PM2启动（推荐）
npm install -g pm2
pm2 start npm --name "super-insight" -- start
pm2 save
pm2 startup

# 8. 配置Nginx反向代理（可选）
sudo apt-get install nginx
# 配置Nginx指向localhost:3001
```

3. 确保应用运行正常

### 测试中执行（30-60分钟）

**开场白**（告诉用户）:
```
今天我们会测试一款AI内容策略工具。
整个过程大约30-60分钟。

请你按照自己的理解去操作，在操作过程中，
尽量说出你的想法，比如：
- 你在寻找什么功能
- 你对某个界面的第一印象
- 你遇到的任何困惑或问题

没有对错之分，你的真实感受对我们非常重要。
```

**引导用户完成5个场景**:
1. **快消品完整流程**（15分钟） - 创建项目→上传→洞察→选题→脚本
2. **批量操作**（5分钟） - 使用快捷键和批量功能
3. **数据查看**（5分钟） - 查看统计和时间线
4. **自由探索**（10分钟） - 让用户自己探索
5. **错误处理**（5分钟） - 测试系统错误提示

**重点记录**:
- 用户卡住的地方（在哪里，为什么，多久）
- 用户的口头反馈（边操作边说的）
- 用户的情绪变化（兴奋、困惑、失望等）
- 用户提到的功能需求

### 测试后跟进（10分钟）

**立即完成**:
1. 整理测试记录
2. 标记关键问题
3. 感谢用户（口头+礼品）

**后续跟进**:

## ⚠️ 常见问题

### 部署相关

**Q: API Key哪里获取？**
A: 访问 https://console.anthropic.com/ 注册并获取

**Q: 部署后无法访问？**
A: 检查：
1. 端口是否开放（3001）
2. 防火墙设置
3. 环境变量是否正确配置

**Q: API请求失败？**
A: 检查：
1. API Key是否正确
2. API额度是否充足
3. 网络是否可以访问Anthropic API

### 测试相关

**Q: 招募不到用户怎么办？**
A: 
1. 扩大招募渠道（多个社群发布）
2. 提高激励（增加礼品价值）
3. 放宽筛选标准（只要有相关经验即可）

**Q: 用户反馈质量不高怎么办？**
A: 
1. 使用引导式测试（不要让用户盲目探索）
2. 多问"为什么"（深挖用户想法）
3. 观察行为而非只听话语

**Q: 测试数据如何分析？**
A: 使用提供的`USER_TESTING_SUMMARY_TEMPLATE.md`，包含：
- 定量数据统计表
- 定性问题分类
- 改进优先级排序
