# 📊 PPT 在线查看方式

## 方法1：GitHub 在线预览

访问以下链接查看 PPT 源文件：
https://github.com/aiqing20230305-bot/DVX/blob/DVX/docs/presentation.md

GitHub 会自动渲染 Markdown 格式。

## 方法2：使用 Marp Web（推荐）

1. 访问：https://web.marp.app/
2. 点击 "Upload" 或直接拖拽文件
3. 上传 `docs/presentation.md`
4. 在线查看和导出

## 方法3：本地导出

```bash
# 安装 Marp CLI
npm install -g @marp-team/marp-cli

# 导出 PDF
bash scripts/export-ppt.sh
```

## 方法4：VS Code 预览

1. 安装插件：[Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode)
2. 打开 `docs/presentation.md`
3. 按 Ctrl+Shift+V 预览

## 快速阅读版本
