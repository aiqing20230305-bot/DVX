## 🎯 功能2: PDF导出

### 业务需求

**用户痛点**:
- PDF适合归档和邮件分享（不可编辑）
- 部分场景下需要PDF格式（如邮件附件、合同附件）
- PDF文件更小，更易传输

**解决方案**:
使用jsPDF + html2canvas在浏览器端生成PDF

### 技术设计

#### 技术选型

**方案1**: jsPDF + html2canvas（推荐）
- **优点**: 
  - 纯前端实现，无需后端服务
  - 支持HTML渲染，样式保真度高
  - 支持中文字体
- **缺点**: 
  - 生成速度较慢（5-10秒）
  - 文件较大（HTML转图片）

**方案2**: pdfmake（备选）
- **优点**: 
  - 文件小，生成快
  - API简洁
- **缺点**: 
  - 需要手动构建文档结构
  - 样式控制复杂
  - 不支持复杂布局

**选择**: 方案1（jsPDF + html2canvas）

#### 实现方案

**前端实现** (浏览器端生成)

**新增依赖**:
```bash
npm install jspdf html2canvas
```

**文件**: `src/utils/pdf-export.ts`

```typescript
import jsPDF from 'jspdf'
import html2canvas from 'html2canvas'

export async function exportReportToPDF(reportHtml: string, filename: string): Promise<void> {
  // 1. 创建临时容器
  const container = document.createElement('div')
  container.innerHTML = reportHtml
  container.style.width = '210mm' // A4宽度
  container.style.position = 'absolute'
  container.style.left = '-9999px'
  document.body.appendChild(container)
  
  try {
    // 2. 使用html2canvas渲染HTML为canvas
    const canvas = await html2canvas(container, {
      scale: 2, // 提高清晰度
      useCORS: true,
      backgroundColor: '#0D0D0D'
    })
    
    // 3. 创建PDF
    const pdf = new jsPDF({
      orientation: 'portrait',
      unit: 'mm',
      format: 'a4'
    })
    
    // 4. 将canvas转为图片并添加到PDF
    const imgData = canvas.toDataURL('image/png')
    const imgWidth = 210 // A4宽度（mm）
    const imgHeight = (canvas.height * imgWidth) / canvas.width
    
    pdf.addImage(imgData, 'PNG', 0, 0, imgWidth, imgHeight)
    
    // 5. 保存PDF
    pdf.save(filename)
  } finally {
    // 6. 清理临时容器
    document.body.removeChild(container)
  }
}
```

**问题1**: 生成速度慢

**问题3**: 中文字体
- **解决**: jsPDF默认支持中文（使用Unicode字体）

### 技术设计

#### 图表渲染方案

**方案**: Recharts → Canvas → 图片 → PPT/PDF

**流程**:
1. 使用Recharts在隐藏的DOM中渲染图表
2. 使用html2canvas将图表转为canvas
3. 将canvas转为base64图片
4. 将图片嵌入PPT（pptxgenjs支持base64图片）

**工具函数**: `src/utils/chart-to-image.ts`

```typescript
import html2canvas from 'html2canvas'

export async function chartToImage(chartElement: HTMLElement): Promise<string> {
  const canvas = await html2canvas(chartElement, {
    scale: 2,
    backgroundColor: '#1A1A1A' // 卡片背景
  })
  return canvas.toDataURL('image/png')
}
```

## 🔮 风险与对策

### 风险1: PDF生成速度慢

**风险等级**: 中

**影响**: 用户等待时间长，体验差

**对策**:
- 添加进度提示
- 使用Web Worker后台生成
- 降低图片质量（scale: 1.5）

### 风险2: 图表清晰度不够

**风险等级**: 低

**影响**: 图表模糊，专业度下降

**对策**:
- 使用高分辨率渲染（scale: 2）
- 调整图表尺寸和字体大小
- 使用PNG格式而非JPEG

### 风险3: 中文字体支持

**风险等级**: 低

**影响**: PDF中文显示异常

**对策**:
- jsPDF默认支持Unicode
- 测试验证中文显示
- 如有问题，引入中文字体文件
