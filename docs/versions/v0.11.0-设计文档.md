# v0.11.0 在线测试问卷组件 - 设计文档

**版本号**: v0.11.0  
**开始时间**: 2026-04-06  
**功能主题**: 在线测试问卷组件

---

## 📋 产品目标

**核心价值**: 结构化、实时的用户反馈收集

让测试管理员能够创建自定义问卷，在测试过程中的特定时机弹出问卷，收集结构化的用户反馈数据。

---

## 🎯 功能需求

### 1. 问卷模板管理
- 创建新问卷（标题、描述、触发条件）
- 编辑已有问卷
- 删除问卷
- 问卷列表查看

### 2. 题型支持
- **单选题** - Radio buttons
- **多选题** - Checkboxes
- **文本题** - Text input/textarea
- **评分题** - 1-5星评分

### 3. 触发机制
- **手动触发**: 测试管理员点击按钮弹出
- **定时触发**: 测试开始后N分钟弹出
- **事件触发**: 特定操作后弹出（如完成某个流程）

### 4. 答题流程
- 问卷弹窗（Modal形式）
- 题目逐一展示或全部展示
- 必答题验证
- 提交后自动关闭

### 5. 数据分析
- 问卷回答率统计
- 各题答案分布
- 文本答案汇总
- 评分平均值

## 🗄️ 数据库设计

### 表1: questionnaires
```sql
CREATE TABLE IF NOT EXISTS questionnaires (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  description TEXT,
  trigger_type TEXT NOT NULL,  -- 'manual', 'timed', 'event'
  trigger_value TEXT,           -- 触发参数（如时间、事件名）
  status TEXT NOT NULL DEFAULT 'active',  -- 'active', 'archived'
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

### 表2: questions
```sql
CREATE TABLE IF NOT EXISTS questions (
  id TEXT PRIMARY KEY,
  questionnaire_id TEXT NOT NULL,
  question_type TEXT NOT NULL,  -- 'radio', 'checkbox', 'text', 'rating'
  question_text TEXT NOT NULL,
  options TEXT,                 -- JSON array, 仅radio/checkbox需要
  required INTEGER NOT NULL DEFAULT 0,  -- 0=可选, 1=必答
  order_index INTEGER NOT NULL,
  created_at INTEGER NOT NULL,
  FOREIGN KEY (questionnaire_id) REFERENCES questionnaires(id) ON DELETE CASCADE
);
```

### 表3: questionnaire_responses (复用feedback_responses或新建)
**选择**: 扩展现有的feedback_responses表

```sql
-- 添加字段
ALTER TABLE feedback_responses ADD COLUMN questionnaire_id TEXT;
ALTER TABLE feedback_responses ADD COLUMN question_id TEXT;
ALTER TABLE feedback_responses ADD COLUMN question_type TEXT;
```

## 🔄 工作流程

### 管理员创建问卷
1. 访问 `/testing/questionnaires`
2. 点击"创建问卷"
3. 填写问卷信息（标题、描述、触发方式）
4. 添加问题（选择题型、输入问题、设置选项）
5. 保存问卷

### 测试中触发问卷
**手动触发**:
1. 测试管理员在会话详情页点击"发送问卷"
2. 选择要发送的问卷
3. 测试用户看到问卷弹窗

**定时触发**:
1. 测试开始后计时器运行
2. 达到设定时间自动弹出问卷

**事件触发**:
1. 监听特定用户操作（通过useTestingTracker）
2. 满足条件时自动弹出问卷

### 用户答题
1. 看到问卷弹窗
2. 逐题回答（必答题必须填写）
3. 点击"提交答案"
4. 答案保存到数据库

### 数据分析
1. 管理员进入问卷统计页
2. 查看回答率、答案分布、评分均值
3. 导出统计报告
