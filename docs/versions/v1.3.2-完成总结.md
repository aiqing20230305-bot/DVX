## 💡 技术亮点

### 1. API方法签名优化

**修改前**:
```typescript
delete: <T>(path: string, config?: RequestConfig) =>
  request<T>(path, { method: 'DELETE' }, config)
```

**修改后**:
```typescript
delete: <T>(path: string, body?: unknown, config?: RequestConfig) =>
  request<T>(path, { method: 'DELETE', body: body ? JSON.stringify(body) : undefined }, config)
```

**优势**: DELETE方法现在支持body参数，与POST/PUT/PATCH保持一致

### 2. Badge组件类型扩展

**修改**:
```typescript
type BadgeVariant = ... | 'secondary'

const variantClasses: Record<BadgeVariant, string> = {
  ...
  secondary: 'bg-slate-600 text-slate-200 ring-1 ring-slate-500',
}
```

**优势**: 支持更多的徽章变体，提升组件灵活性

### 3. null到undefined转换

**修改前**:
```typescript
templateId: selectedTemplate  // string | null
```

**修改后**:
```typescript
templateId: selectedTemplate ?? undefined  // string | undefined
```

**优势**: 符合TypeScript最佳实践，避免null/undefined混用
