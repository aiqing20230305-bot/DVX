### 2. 键盘快捷键支持

**新增Hook**: `usePageKeyboardShortcuts`

**实现特性**:
- 页面级快捷键管理
- 自动过滤输入框场景（INPUT/TEXTAREA）
- 支持Ctrl/Cmd键跨平台兼容
- 可配置启用/禁用状态
- preventDefault可选

**代码实现**:
```typescript
export function usePageKeyboardShortcuts(
  shortcuts: PageKeyboardShortcut[],
  options: UsePageKeyboardShortcutsOptions = {}
) {
  const { enabled = true, preventDefault = true } = options

  useEffect(() => {
    if (!enabled) return

    const handleKeyDown = (e: KeyboardEvent) => {
      // 在输入框中不触发快捷键
      const target = e.target as HTMLElement
      const tagName = target.tagName.toUpperCase()
      const isEditable = target.isContentEditable

      if (tagName === 'INPUT' || tagName === 'TEXTAREA' || isEditable) {
        return
      }

      // 检查快捷键匹配
      for (const shortcut of shortcuts) {
        const ctrlMatch = (e.ctrlKey || e.metaKey) === (shortcut.ctrl ?? false)
        const shiftMatch = e.shiftKey === (shortcut.shift ?? false)
        const altMatch = e.altKey === (shortcut.alt ?? false)
        const keyMatch = e.key.toLowerCase() === shortcut.key.toLowerCase()

        if (ctrlMatch && shiftMatch && altMatch && keyMatch) {
          if (preventDefault) {
            e.preventDefault()
          }
          shortcut.handler()
          break
        }
      }
    }

    window.addEventListener('keydown', handleKeyDown)
    return () => window.removeEventListener('keydown', handleKeyDown)
  }, [shortcuts, enabled, preventDefault])
}
```

**支持的快捷键**:

| 快捷键 | 功能 | 页面 |

| Ctrl/Cmd+A | 全选所有项 | Insights / Topics |
| Ctrl/Cmd+D | 取消选择 | Insights / Topics |

### 3. 快捷键帮助面板

**新增组件**: `KeyboardShortcutsHelp`

**实现特性**:
- 模态对话框显示快捷键列表
- 自动格式化快捷键显示（kbd标签）
- 平台自适应（Mac显示Cmd，Windows显示Ctrl）
- 点击外部/关闭按钮可关闭
- 清晰的快捷键分组展示

**代码实现**:
```typescript
export function KeyboardShortcutsHelp({
  open,
  onClose,
  shortcuts,
  title = '键盘快捷键'
}: KeyboardShortcutsHelpProps) {
  if (!open) return null

  return (
    <div
      className="fixed inset-0 z-50 flex items-center justify-center bg-black/50 backdrop-blur-sm"
      onClick={onClose}
    >
      <div
        className="bg-slate-800 border border-slate-700 rounded-lg p-6 max-w-md w-full mx-4 shadow-xl"
        onClick={(e) => e.stopPropagation()}
      >
        {/* Header */}
        <div className="flex items-center justify-between mb-4">
          <h3 className="text-lg font-semibold text-slate-100">{title}</h3>
          <button onClick={onClose} className="text-slate-400 hover:text-slate-300">
            <X size={20} />
          </button>
        </div>

        {/* Shortcuts list */}
        <div className="space-y-3 mb-6">
          {shortcuts.map((shortcut, idx) => {
            const keys = formatShortcut(shortcut)
            return (
              <div key={idx} className="flex items-center justify-between">
                <span className="text-sm text-slate-400">{shortcut.description}</span>
                <div className="flex gap-1">
                  {keys.map((key, i) => (
                    <kbd key={i} className="px-2 py-1 text-xs font-medium bg-slate-700 text-slate-300 rounded border border-slate-600">
                      {key}
                    </kbd>
                  ))}
                </div>
              </div>
            )
          })}
        </div>

        {/* Footer tip */}
        <div className="text-xs text-slate-500 text-center">
          💡 在输入框中快捷键会被禁用
        </div>
      </div>
    </div>
  )
}
```

**辅助函数**:
```typescript
// 获取平台修饰键
export function getModifierKey(): string {
  const isMac = navigator.platform.toUpperCase().indexOf('MAC') >= 0
  return isMac ? 'Cmd' : 'Ctrl'
}

// 格式化快捷键显示
export function formatShortcut(shortcut: PageKeyboardShortcut): string[] {
  const keys: string[] = []
  if (shortcut.ctrl) keys.push(getModifierKey())
  if (shortcut.shift) keys.push('Shift')
  if (shortcut.alt) keys.push('Alt')
  
  let keyDisplay = shortcut.key
  if (shortcut.key.toLowerCase() === 'delete') keyDisplay = 'Delete'
  else if (shortcut.key.toLowerCase() === 'escape') keyDisplay = 'Esc'
  else keyDisplay = shortcut.key.toUpperCase()
  
  keys.push(keyDisplay)
  return keys
}
```

## 💡 技术亮点

### 1. 跨平台键盘兼容

**问题**: Windows使用Ctrl键，Mac使用Cmd键

**解决方案**:
```typescript
// 检测时兼容两种键
const ctrlMatch = (e.ctrlKey || e.metaKey) === (shortcut.ctrl ?? false)

// 显示时自适应平台
export function getModifierKey(): string {
  const isMac = navigator.platform.toUpperCase().indexOf('MAC') >= 0
  return isMac ? 'Cmd' : 'Ctrl'
}
```

**优势**:
- 一套代码，两个平台
- 用户无需关心平台差异
- 帮助文档自动适配

const target = e.target as HTMLElement

## 🎓 经验总结

### 1. 键盘快捷键设计原则

**DO - 应该做的**:
- ✅ 遵循常见约定（Ctrl+A全选、Delete删除）
- ✅ 提供帮助文档（Ctrl+/）
- ✅ 跨平台兼容（Ctrl/Cmd）
- ✅ 在输入场景禁用
- ✅ 提供视觉反馈（Toast提示）
- ✅ 危险操作仍需确认（Delete仍显示对话框）

**DON'T - 不应该做的**:
- ❌ 覆盖浏览器常用快捷键（Ctrl+S保存、Ctrl+P打印）
- ❌ 在输入框中触发快捷键
- ❌ 使用难以发现的快捷键组合
- ❌ 没有帮助文档
- ❌ 不支持跨平台

### 2. 批量导出用户体验设计

**之前的问题**:
```
用户流程:
1. 批量选择5个洞察
2. 点击"导出"
3. 弹出确认框："导出已选 or 导出全部？"
4. 选择"导出已选"
5. 才真正导出

问题: 用户已经明确选择了，为什么还要再次确认范围？
```

**优化后**:
```
用户流程:
1. 批量选择5个洞察
2. 点击"导出已选"（意图明确）
3. 直接导出

优势:
- 操作步骤减少66%
- 意图清晰，无歧义
- 非破坏性操作，无需二次确认
```

**设计原则**:
- 破坏性操作（删除）需要确认 ✅
- 非破坏性操作（导出）不需要确认 ✅
- 用户意图明确时不要多余确认 ✅
