## 🎯 需要修复的类型错误

### 类别1: API RequestConfig错误（3个）

**文件**: 
- `src/api/insight.api.ts:12`
- `src/api/script.api.ts:15`
- `src/api/topic.api.ts:12`

**错误信息**:
```
Object literal may only specify known properties, 
and 'ids' does not exist in type 'RequestConfig'.
```

**问题**: API调用时传入了`ids`参数，但RequestConfig类型中没有定义

**修复方案**: 
- 方案A：在RequestConfig中添加`ids`属性
- 方案B：将`ids`作为URL参数或body传递（推荐）

---

### 类别2: BadgeVariant类型错误（5个）

**文件**:
- `src/pages/ProjectDashboard.tsx:174`
- `src/pages/ProjectDashboard.tsx:190`
- `src/pages/Projects.tsx:208`
- `src/pages/Projects.tsx:213`
- `src/pages/Projects.tsx:227`

**错误信息**:
```
Type '"secondary"' is not assignable to type 'BadgeVariant | undefined'.
```

**问题**: 使用了`"secondary"`变体，但Badge组件类型中未定义

**修复方案**: 在BadgeVariant类型中添加`"secondary"`

---

### 类别3: Sidebar string | null错误（1个）

**文件**: `src/components/layout/Sidebar.tsx:57`

**错误信息**:
```
Type 'string | null' is not assignable to type 'string | undefined'.
Type 'null' is not assignable to type 'string | undefined'.
```

**问题**: localStorage.getItem返回`string | null`，但期望`string | undefined`

**修复方案**: 使用`?? undefined`将null转换为undefined

---

### 类别4: Workbench CreateProjectInput错误（1个）

**文件**: `src/pages/Workbench.tsx:81`

**错误信息**:
```
Argument of type 'string' is not assignable to parameter of type 'CreateProjectInput'.
```

**问题**: 传递了string类型，但期望CreateProjectInput对象

**修复方案**: 检查函数调用，传递正确的对象结构

---

### 类别5: Insight.category不存在（1个）

**文件**: `src/utils/export.utils.ts:12`

**错误信息**:
```
Property 'category' does not exist on type 'Insight'.
```

**问题**: Insight类型中没有category属性

**修复方案**: 从导出逻辑中移除category或更新Insight类型
