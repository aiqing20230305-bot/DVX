## 💡 技术亮点

### 1. Zustand Store测试模式

**状态重置**:
```typescript
beforeEach(() => {
  useProjectStore.setState({
    projects: [],
    activeProjectId: null,
    loading: false
  })
})
```

**优势**:
- 每个测试独立
- 状态可预测
- 测试可靠

### 2. 异步操作测试

**Mock Fetch**:
```typescript
global.fetch = vi.fn().mockResolvedValue({
  ok: true,
  json: async () => ({ success: true })
})

await batchUpdateSelected(['1'], true)

expect(global.fetch).toHaveBeenCalledWith('/api/insight/batch', {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ ids: ['1'], selected: true })
})
```

**优势**:
- 完整的API调用验证
- 请求参数验证
- 响应处理验证

### 3. Set数据结构测试

**选择状态测试**:
```typescript
toggleSelection('1')
expect(useInsightStore.getState().selectedIds.has('1')).toBe(true)

toggleSelection('1')
expect(useInsightStore.getState().selectedIds.has('1')).toBe(false)
```

**优势**:
- 验证Set操作正确性
- 验证状态一致性

### 4. 复杂状态变更测试

**级联更新**:
```typescript
// 删除项目时自动切换活跃项目
await removeProject('1')

const { projects, activeProjectId } = useProjectStore.getState()
expect(projects).toHaveLength(1)
expect(activeProjectId).toBe('2') // Auto-switch
```

**优势**:
- 验证业务逻辑正确
- 验证边界情况
