## 🎯 测试优先级分析

### 高优先级（必须测试）

**1. 复杂组件测试**:
- `InsightCard.tsx` - 洞察卡片组件（选择、优先级、证据链展开）
- `TopicCard.tsx` - 选题卡片组件（平台、优先级、选择）
- `ScriptCard.tsx` - 脚本卡片组件（版本切换、编辑）

**原因**: 核心业务组件，用户交互频繁，逻辑复杂

**2. Hooks补充测试**:
- `useSSEStream.test.ts` - SSE流式传输测试（连接、断开、错误）
- `useFileUpload.test.ts` - 文件上传边界测试（大文件、错误类型）

**原因**: 关键业务逻辑，需要边界覆盖

**3. 工具函数补充测试**:
- `export.utils.test.ts` - 导出工具边界测试（空数据、特殊字符）
- `date.test.ts` - 日期工具边界测试（边界值、时区）

**原因**: 工具函数包含业务逻辑，需要完整覆盖

### 中优先级（可选）

**4. 数据面板组件**:
- `ProjectStats.tsx` - 项目统计面板
- `ActivityChart.tsx` - 活动趋势图

**原因**: 展示型组件，逻辑相对简单
