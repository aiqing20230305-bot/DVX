## 💡 技术亮点

### 1. 组件交互测试

**事件处理验证**:
```typescript
it('calls onClick handler when clicked', () => {
  const handleClick = vi.fn()
  render(<Button onClick={handleClick}>Click me</Button>)
  
  fireEvent.click(screen.getByText('Click me'))
  
  expect(handleClick).toHaveBeenCalledTimes(1)
})
```

**优势**:
- 验证用户交互正确
- 确保回调函数调用
- 防止交互逻辑回归

### 2. 条件渲染测试

**开关状态验证**:
```typescript
it('renders nothing when closed', () => {
  const { container } = render(<ConfirmDialog {...props} open={false} />)
  expect(container.firstChild).toBeNull()
})

it('renders dialog when open', () => {
  render(<ConfirmDialog {...props} open={true} />)
  expect(screen.getByText('Confirm Action')).toBeInTheDocument()
})
```

**优势**:
- 验证显示/隐藏逻辑
- 确保条件渲染正确
- 防止UI状态错误

### 3. 外部点击事件测试

**Dropdown关闭逻辑**:
```typescript
it('closes dropdown when clicking outside', () => {
  render(
    <div>
      <SortDropdown {...props} />
      <div data-testid="outside">Outside</div>
    </div>
  )
  
  fireEvent.click(screen.getByText('创建时间'))
  expect(screen.getByText('更新时间')).toBeInTheDocument()
  
  fireEvent.mouseDown(screen.getByTestId('outside'))
  expect(screen.queryByText('更新时间')).not.toBeInTheDocument()
})
```

**优势**:
- 验证点击外部关闭
- 模拟真实用户行为
- 确保交互体验正确

### 4. Timer Mock测试

**Toast自动移除**:
```typescript
beforeEach(() => {
  vi.useFakeTimers()
})

afterEach(() => {
  vi.useRealTimers()
})

it('auto-removes toast after default duration', () => {
  toast.success('Auto Remove')
  
  let { toasts } = useToastStore.getState()
  expect(toasts).toHaveLength(1)
  
  vi.advanceTimersByTime(5000)
  
  toasts = useToastStore.getState().toasts
  expect(toasts).toHaveLength(0)
})
```

**优势**:
- 验证定时器逻辑
- 快速测试时间相关功能
- 无需真实等待
