# v0.13.0 测试报告生成与导出系统 - 设计文档

**版本号**: v0.13.0  
**开始时间**: 2026-04-06  
**功能主题**: 测试报告生成与导出系统

---

## 📋 产品目标

**核心价值**: 将测试数据转化为可视化报告并支持导出，形成测试数据闭环

让测试管理员能够快速生成测试报告，导出Excel/PDF格式，便于分享、存档和决策汇报。

---

## 🎯 功能需求

### 1. 数据聚合

汇总测试数据：
- 会话统计（总数、活跃数、平均时长）
- 问卷统计（总数、回答率、问题分布）
- 行为统计（操作数、页面访问、点击热点）
- 反馈统计（问题类型、满意度）

### 2. 报告预览

可视化展示：
- 测试概览（关键指标卡片）
- 会话列表（表格展示）
- 问卷分析（图表展示）
- 行为分析（时间线、热力图）

### 3. Excel导出

生成多sheet工作簿：
- **Sheet1: 测试概览** - 关键指标汇总
- **Sheet2: 会话列表** - 所有测试会话
- **Sheet3: 问卷数据** - 问卷回答明细
- **Sheet4: 行为数据** - 用户操作明细
- **Sheet5: 反馈汇总** - 用户反馈内容

### 4. PDF导出（可选）

生成PDF报告：
- 封面页（测试标题、日期）
- 测试概览
- 数据图表
- 详细数据表格

### 5. 导出配置

灵活配置：
- 选择导出内容（全部/部分）
- 选择时间范围
- 选择特定会话
- 选择特定问卷

// testSession.repo.ts
getTestingReport(filters: { start?: number, end?: number }): TestingReport {
  // 1. 聚合概览统计
  const overview = this.getOverviewStats(filters)
  
  // 2. 获取会话列表（带操作数和反馈数）
  const sessions = this.getSessionsWithStats(filters)
  
  // 3. 获取问卷数据（带回答统计）
  const questionnaires = this.getQuestionnairesWithStats(filters)
  
  // 4. 获取行为数据
  const actions = this.getActions(filters)
  
  // 5. 获取反馈数据
  const feedback = this.getFeedback(filters)
  
  return {
    overview,
    sessions,
    questionnaires,
    actions,
    feedback
  }
}

### Excel生成

```typescript
// report.service.ts
export function generateTestingReportExcel(report: TestingReport): Buffer {
  const workbook = XLSX.utils.book_new()
  
  // Sheet1: 测试概览
  const overviewData = [
    { '指标': '总会话数', '数值': report.overview.total_sessions },
    { '指标': '活跃会话', '数值': report.overview.active_sessions },
    // ...
  ]
  const overviewSheet = XLSX.utils.json_to_sheet(overviewData)
  XLSX.utils.book_append_sheet(workbook, overviewSheet, '测试概览')
  
  // Sheet2: 会话列表
  const sessionsData = report.sessions.map(s => ({
    '会话ID': s.id,
    '用户名': s.user_name,
    '角色': s.user_role,
    '场景': s.scenario,
    '状态': s.status,
    '开始时间': new Date(s.start_time).toLocaleString('zh-CN'),
    '结束时间': s.end_time ? new Date(s.end_time).toLocaleString('zh-CN') : '进行中',
    '时长（秒）': s.duration || 0,
    '操作数': s.action_count,
    '反馈数': s.feedback_count
  }))
  const sessionsSheet = XLSX.utils.json_to_sheet(sessionsData)
  XLSX.utils.book_append_sheet(workbook, sessionsSheet, '会话列表')
  
  // Sheet3: 问卷数据
  const questionnaireData: any[] = []
  report.questionnaires.forEach(q => {
    q.questions.forEach(question => {
      if (question.answer_distribution) {
        Object.entries(question.answer_distribution).forEach(([option, count]) => {
          const total = Object.values(question.answer_distribution!).reduce((a, b) => a + b, 0)
          questionnaireData.push({
            '问卷标题': q.title,
            '问题文本': question.question_text,
            '问题类型': question.question_type,
            '选项': option,
            '回答数': count,
            '百分比': `${Math.round((count / total) * 100)}%`
          })
        })
      } else if (question.average_rating !== undefined) {
        questionnaireData.push({
          '问卷标题': q.title,
          '问题文本': question.question_text,
          '问题类型': question.question_type,
          '选项': '平均评分',
          '回答数': '',
          '百分比': question.average_rating.toFixed(1)
        })
      }
    })
  })
  const questionnaireSheet = XLSX.utils.json_to_sheet(questionnaireData)
  XLSX.utils.book_append_sheet(workbook, questionnaireSheet, '问卷数据')
  
  // Sheet4: 行为数据
  const actionsData = report.actions.map(a => ({
    '会话ID': a.session_id.slice(0, 8),
    '用户名': a.user_name,
    '操作类型': a.action_type,
    '页面': a.page,
    '目标': a.target || '',
    '详情': a.details || '',
    '时间戳': new Date(a.timestamp).toLocaleString('zh-CN')
  }))
  const actionsSheet = XLSX.utils.json_to_sheet(actionsData)
  XLSX.utils.book_append_sheet(workbook, actionsSheet, '行为数据')
  
  // Sheet5: 反馈汇总
  const feedbackData = report.feedback.map(f => ({
    '会话ID': f.session_id.slice(0, 8),
    '用户名': f.user_name,
    '问题': f.question_text,
    '回答': f.answer,
    '时间': new Date(f.created_at).toLocaleString('zh-CN')
  }))
  const feedbackSheet = XLSX.utils.json_to_sheet(feedbackData)
  XLSX.utils.book_append_sheet(workbook, feedbackSheet, '反馈汇总')
  
  return XLSX.write(workbook, { type: 'buffer', bookType: 'xlsx' })
}
```
