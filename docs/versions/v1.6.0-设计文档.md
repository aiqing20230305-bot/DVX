## 🎯 性能瓶颈分析

### 当前性能问题

**1. 列表渲染性能**:
- 问题：大数据量时全量渲染，性能下降
- 场景：洞察、选题、脚本列表（可能>100条）
- 影响：滚动卡顿，渲染时间长

**2. 搜索筛选性能**:
- 问题：每次输入触发全量搜索
- 场景：实时搜索输入
- 影响：输入延迟，CPU占用高

**3. 组件重渲染**:
- 问题：不必要的组件重渲染
- 场景：父组件state变化导致子组件重渲染
- 影响：CPU浪费，交互延迟

**4. 数据请求优化**:
- 问题：重复请求相同数据
- 场景：页面切换、刷新
- 影响：网络请求多，加载时间长

```typescript
import { FixedSizeList } from 'react-window'

interface VirtualListProps<T> {
  items: T[]
  itemHeight: number
  height: number
  renderItem: (item: T, index: number) => React.ReactNode
}

export function VirtualList<T>({ items, itemHeight, height, renderItem }: VirtualListProps<T>) {
  const Row = ({ index, style }: { index: number; style: React.CSSProperties }) => (
    <div style={style}>{renderItem(items[index], index)}</div>
  )

  return (
    <FixedSizeList
      height={height}
      itemCount={items.length}
      itemSize={itemHeight}
      width="100%"
    >
      {Row}
    </FixedSizeList>
  )
}
```

### Task 2: 搜索防抖优化（20分钟）

**目标**: 减少搜索输入时的计算频率

**技术方案**: 使用useDebouncedValue自定义Hook

**实现步骤**:

1. **创建防抖Hook**（10分钟）:
```typescript
// src/hooks/useDebounce.ts
import { useState, useEffect } from 'react'

export function useDebounce<T>(value: T, delay: number = 300): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value)

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}
```

2. **集成到搜索组件**（10分钟）:
```typescript
// 在Insights.tsx中
const [searchQuery, setSearchQuery] = useState('')
const debouncedSearchQuery = useDebounce(searchQuery, 300)

// 使用debouncedSearchQuery进行筛选
const filteredInsights = useMemo(() => {
  return insights.filter(i => 
    i.title.includes(debouncedSearchQuery) ||
    i.summary.includes(debouncedSearchQuery)
  )
}, [insights, debouncedSearchQuery])
```

**预期效果**:
- 搜索输入流畅，无延迟
