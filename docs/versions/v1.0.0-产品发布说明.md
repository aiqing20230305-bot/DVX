## 🎉 产品概述

**超级洞察**是一款AI驱动的短视频内容战略平台，帮助品牌方、代运营公司和内容创作者从市场数据中快速生成洞察、策划选题、创作脚本。

**核心价值**:
- 📊 **数据→洞察**：AI分析市场数据，生成6-12条策略洞察
- 💡 **洞察→选题**：基于洞察生成8-10个高转化内容选题
- 📝 **选题→脚本**：A/B两版本脚本，可直接用于拍摄
- ⚡ **效率提升**：完整流程从数天缩短到2小时内

## 🌟 核心功能

### 1. 完整的内容策略工作流

**数据上传** → **智能解析** → **洞察生成** → **选题策划** → **脚本创作** → **数据导出**

- ✅ 支持多种文件格式（Excel、CSV、PDF、Word）
- ✅ 实时流式生成（SSE技术，边生成边展示）
- ✅ A/B两版本脚本（情感驱动型 + 理性驱动型）
- ✅ 完整的项目管理和时间线记录

### 2. 高效的数据管理

**搜索、筛选、排序三件套**:
- 🔍 **全局搜索**：实时搜索洞察/选题/脚本
- 🎯 **高级筛选**：按平台/优先级/状态筛选
- 📊 **多维排序**：优先级/创建时间/标题排序

### 3. 强大的批量操作

- ☑️ 批量选择（全选/清空/部分选择）
- 🏷️ 批量标记（已选/取消）
- ⭐ 批量设置优先级（1-5星）
- 🗑️ 批量删除（带确认保护）
- 📥 批量导出（Excel格式）

### 4. 专业的快捷键支持

| 快捷键 | 功能 | 适用页面 |

### 5. 直观的数据可视化

## 💡 产品理念

### 设计原则

1. **简单优于复杂**: 功能易用比功能丰富更重要
2. **效率第一**: 批量操作、快捷键、实时生成
3. **用户导向**: 基于真实需求，而非臆测
4. **质量优先**: 稳定可靠比快速迭代更重要

### 开发理念

1. **文档驱动**: 文档与代码同步更新
2. **测试优先**: 质量保证在功能开发之前
3. **渐进增强**: 先核心功能，再辅助工具
4. **克制的艺术**: 知道何时停止和何时开始一样重要
