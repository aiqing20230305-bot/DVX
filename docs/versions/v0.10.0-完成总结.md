```typescript
const [isTracking, setIsTracking] = useState(() => {
  const trackingSessionId = localStorage.getItem('testing_session_id')
  return trackingSessionId === id
})

const handleToggleTracking = () => {
  if (isTracking) {
    stopTestingTracking()
    setIsTracking(false)
    toast.success('追踪已停止', '不再记录用户操作')
  } else {
    if (id) {
      startTestingTracking(id)
      setIsTracking(true)
      toast.success('追踪已启动', '自动记录用户操作')
    }
  }
}
```

## 🔄 工作流程

### 启动追踪
1. 测试管理员创建测试会话
2. 进入会话详情页（`/testing/session/:id`）
3. 点击"启动追踪"按钮
4. localStorage存储`testing_session_id`
5. 右下角显示紫色追踪指示器

### 自动记录
- 测试用户点击任意元素 → 发送API请求记录
- 测试用户切换页面 → 记录导航+停留时长
- 应用发生JS错误 → 自动捕获并记录

### 查看数据
- 操作记录实时存入数据库（user_actions表）
- 会话详情页"操作时间线"区域展示
- 按时间倒序排列

### 停止追踪
- 点击详情页"停止追踪"按钮
- 或点击指示器X按钮
- localStorage清除session_id
- 指示器消失

## 💡 创新点

### 1. 无感知设计
- 用户无需任何额外操作
- 后台静默运行
- 对性能影响极小（防抖+条件启用）

### 2. 会话绑定
- localStorage持久化
- 刷新页面不丢失
- 支持多标签页

### 3. 事件代理模式
- 单个全局监听器
- 自动捕获所有点击
- 动态获取元素描述

### 4. 防抖优化
- 1秒内相同类型操作仅记录一次
- 避免频繁网络请求
- 减轻服务器压力
