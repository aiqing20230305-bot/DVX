### 🔍 知识库AI智能搜索（v2.2.0）

#### 核心技术

**FTS5全文检索**：
- SQLite FTS5虚拟表
- BM25相关性排序算法
- 中文分词支持
- 自动同步触发器（insert/update/delete）

**数据库设计**：
```sql
CREATE VIRTUAL TABLE kb_fts USING fts5(
  title, content, tags, 
  content=kb, 
  content_rowid=id, 
  tokenize='unicode61'
)

-- 自动同步触发器
CREATE TRIGGER kb_ai ... AFTER INSERT ON kb
CREATE TRIGGER kb_au ... AFTER UPDATE ON kb
CREATE TRIGGER kb_ad ... AFTER DELETE ON kb
```

**搜索API**：
- 端点：`POST /api/kb/search`
- 参数：`{ query: string, projectId?: string, limit?: number }`
- 返回：`{ results: KBSearchResult[], took: number }`

**前端集成**：
- 双模式切换：基础搜索 / AI智能搜索
- 实时搜索结果
- 结果预览和跳转
- 搜索耗时显示

**核心代码**：
- 服务层：`server/services/kb-ai.service.ts`
- 前端组件：`src/components/kb/KBSearch.tsx`
- 数据库迁移：`server/db/migrations/002-add-kb-fts.ts`

## 已知问题与限制

### 1. PDF生成性能
- **现象**：多文件解析时进度卡在100%
- **原因**：AI分析阶段（Claude API）耗时3-10秒
- **优化**：已改进进度显示为3步（提取→分析→完成）

### 2. PPT图表质量
- **限制**：html2canvas截图分辨率受限
- **影响**：图表在投影时可能模糊
- **建议**：关键演示建议手工优化图表

### 3. 浏览器兼容性
- **支持**：Chrome/Safari 完全支持
- **限制**：Firefox可能存在字体渲染差异
