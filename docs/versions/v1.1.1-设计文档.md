## 📦 功能规划（MVP）

### Task 1: Vitest测试框架搭建

**目标**: 配置Vitest，使测试可运行

**工作内容**:

1. **安装依赖**:
```bash
npm install -D vitest @testing-library/react @testing-library/jest-dom jsdom happy-dom
```

2. **配置Vitest** (`vitest.config.ts`):
```typescript
import { defineConfig } from 'vitest/config'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'jsdom',
    globals: true,
    setupFiles: './src/test/setup.ts',
  },
})
```

3. **测试setup文件** (`src/test/setup.ts`):
```typescript
import '@testing-library/jest-dom'
```

4. **添加测试脚本** (`package.json`):
```json
"scripts": {
  "test": "vitest",
  "test:run": "vitest run"
}
```

**预计工时**: 10分钟
