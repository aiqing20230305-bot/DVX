## 🐛 错误详解

### 错误1: server/index.ts:155 - template possibly undefined

**问题代码**:
```typescript
// Line 124-155
if (templateId) {
  const template = getTemplateById(templateId)
  if (template) {
    // 使用template合并数据
    projectData = { ... }
  }
}

const project = projectRepo.create(projectData)

if (templateId) {
  const template = getTemplateById(templateId)  // ← 重复调用
  if (template && template.knowledgeBase.length > 0) {
    // 创建知识库项
  }
  
  // ← ERROR: template可能undefined
  logRepo.create(project.id, 'create', `创建项目：${project.name}（使用${template.name}模板）`)
} else {
  logRepo.create(project.id, 'create', `创建项目：${project.name}`)
}
```

**问题根因**:
- 第141行重新调用`getTemplateById(templateId)`并在内部`if (template)`块中使用
- 第155行在外部`if (templateId)`块中使用`template`，但此时`template`变量只在内部if块中定义
- TypeScript无法保证外部块中`template`一定有值

**影响**:
- 如果`templateId`存在但`getTemplateById`返回null，则会尝试访问`undefined.name`
- 运行时可能抛出错误

**修复方案**:
在`if (templateId)`块外定义`template`变量，避免重复调用：

```typescript
if (templateId) {
  const template = getTemplateById(templateId)  // 只调用一次
  
  if (template) {
    // 合并template数据
    projectData = { ... }
  }
  
  const project = projectRepo.create(projectData)
  
  // 创建知识库
  if (template && template.knowledgeBase.length > 0) {
    for (const kbItem of template.knowledgeBase) {
      kbRepo.create({ ... })
    }
  }
  
  // 记录日志
  if (template) {
    logRepo.create(project.id, 'create', `创建项目：${project.name}（使用${template.name}模板）`)
  } else {
    logRepo.create(project.id, 'create', `创建项目：${project.name}（模板未找到）`)
  }
} else {
  const project = projectRepo.create(projectData)
  logRepo.create(project.id, 'create', `创建项目：${project.name}`)
}
```

### 错误2: server/routes/video.route.ts:31 - Missing file_type property

**问题代码**:
```typescript
const upload = uploadRepo.create({
  project_id: projectId,
  filename: `video-url-${Date.now()}.mp4`,
  original_name: url.split('/').pop()?.split('?')[0] || 'video-from-url.mp4',
  mime_type: 'video/mp4',
  size: 0,
  status: 'parsing',
  parsed_data: null,
  error_message: null,
  // ← MISSING: file_type
})
```

**问题根因**:
- `Upload`接口定义要求`file_type`字段（必填）
- 该字段类型为: `'market_data' | 'product_info' | 'product_features'`
- video.route.ts创建上传记录时遗漏了此字段

**Upload接口定义** (upload.repo.ts):
```typescript
export interface Upload {
  id: string
  project_id: string
  filename: string
  original_name: string
  mime_type: string
  size: number
  file_type: 'market_data' | 'product_info' | 'product_features'  // ← 必填
  status: 'uploading' | 'parsing' | 'ready' | 'error'
  parsed_data: string | null
  error_message: string | null
  created_at: number
  updated_at: number
}
```

**影响**:
- TypeScript编译失败
- 如果强制运行，数据库插入可能失败（file_type字段NOT NULL）

**修复方案**:
添加`file_type`字段，视频分析通常属于市场数据分析：

```typescript
const upload = uploadRepo.create({
  project_id: projectId,
  filename: `video-url-${Date.now()}.mp4`,
  original_name: url.split('/').pop()?.split('?')[0] || 'video-from-url.mp4',
  mime_type: 'video/mp4',
  size: 0,
  file_type: 'market_data',  // ← 添加此字段
  status: 'parsing',
  parsed_data: null,
  error_message: null,
})
```

**为什么选择market_data**:
- 视频分析通常用于分析竞品、市场趋势、爆款内容
- `product_info`更适合产品说明书、规格文档
- `product_features`更适合产品特性描述
- 视频内容偏向市场洞察，因此归类为`market_data`

### 错误3: server/services/parser/pdf.parser.ts:2,27 - PDFParse incorrect usage

**问题代码**:
```typescript
// Line 2
import { PDFParse } from 'pdf-parse'  // ← 错误的导入方式

// Line 26-27
const parser = new PDFParse(buffer)   // ← 错误：PDFParse不是类
const pdfData = await parser.parse()  // ← 错误：没有parse方法
```

**问题根因**:
- `pdf-parse`库导出的是**默认函数**，不是命名导出
- `pdf-parse`不是一个类，不能用`new`实例化
- 正确用法是直接调用函数：`const data = await pdfParse(buffer)`

**pdf-parse库的正确用法**:
```typescript
import pdfParse from 'pdf-parse'  // 默认导入

const data = await pdfParse(buffer)
// data: {
//   numpages: number,
//   numrender: number,
//   info: object,
//   metadata: object,
//   text: string,
//   version: string
// }
```

**影响**:
- TypeScript编译失败
- 运行时会抛出错误（PDFParse is not a constructor）
- PDF解析功能完全不可用

**修复方案**:
修改导入和调用方式：

```typescript
// 正确的导入
import pdfParse from 'pdf-parse'

// 正确的调用
export async function parsePDF(filePath: string): Promise<PDFParseResult> {
  const buffer = readFileSync(filePath)
  
  let extractedText: string
  let pageCount: number
  
  try {
    // 直接调用函数，不用new
    const pdfData = await pdfParse(buffer)
    
    extractedText = pdfData.text.trim()
    pageCount = pdfData.numpages
    
    if (!extractedText || extractedText.length < 10) {
      throw new Error('PDF文本提取失败或内容为空，可能是扫描版PDF')
    }
    
    // 后续Claude分析逻辑...
  } catch (error) {
    // 错误处理...
  }
}
```
