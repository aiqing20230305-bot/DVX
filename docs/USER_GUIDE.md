## 🚀 快速开始

### 系统要求
- Node.js 18+ (推荐 22.x)
- 现代浏览器 (Chrome/Edge/Safari/Firefox 最新版)
- Claude API Key (Anthropic)

### 安装步骤

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填入你的 ANTHROPIC_API_KEY

# 3. 启动服务
npm run dev
```

### 首次使用

1. **访问应用**: 浏览器打开 `http://localhost:5173`
2. **创建项目**: 点击"新建项目"，选择行业模板（快消品/美妆/母婴等）
3. **上传数据**: 上传电商数据文件（Excel/PDF）
4. **生成洞察**: 点击"生成洞察"，AI 自动分析
5. **策划选题**: 基于洞察生成内容选题
6. **创作脚本**: 选择选题，生成 A/B 两版本脚本
7. **导出报告**: 生成完整战略报告（HTML格式）

**预计时间**: 首次完整流程约 3-5 分钟

## 🔄 核心工作流

### 完整流程图

```
数据上传 → AI洞察 → 选题策划 → 脚本创作 → 战略报告
   ↓         ↓         ↓           ↓          ↓
 解析文件   深度分析   内容规划    A/B测试    导出交付
```

### 1️⃣ 数据工作台 (Workbench)

**功能**: 项目管理 + 数据上传

**操作步骤**:
1. 点击"新建项目"按钮
2. 填写项目信息（名称、描述、品牌等）
3. 选择行业模板（可选）
   - 快消品: 日用品、食品饮料、个护美妆
   - 美妆: 护肤、彩妆、香水
   - 母婴: 奶粉、纸尿裤、玩具
   - 服饰: 女装、男装、童装
   - 家居: 家具、家纺、厨具
4. 保存项目
5. 上传数据文件：
   - **Excel**: 支持 .xlsx/.xls 格式，自动解析表格数据
   - **PDF**: 支持市场报告、竞品分析文档
   - **视频URL**: 支持抖音/快手等平台链接
6. 等待文件解析完成（通常 1-3 秒）

**数据格式建议**:
- Excel 应包含：视频标题、达人、点赞数、销量、GMV 等字段
- PDF 应包含：市场规模、竞品信息、人群画像等内容

**项目统计面板**:
- 洞察数量
- 选题数量
- 脚本数量
- 报告状态

**数据可视化面板**:
- 活动趋势图 (7天/30天/全部)
- 平台分布饼图

### 2️⃣ 洞察引擎 (Insights)

**功能**: AI 分析数据，生成内容洞察

**操作步骤**:
1. 确保已上传并解析数据文件
2. 点击"生成洞察"按钮
3. 观察实时流式输出（AI 正在分析）
4. 生成完成后，查看洞察卡片

**洞察类型**:
- 🔥 **趋势信号**: 市场趋势、热点话题
- 💡 **机会缺口**: 未被充分覆盖的内容方向
- 🎯 **竞品分析**: 竞品优势与薄弱环节
- 📊 **数据洞察**: 基于数据的深度发现
- ⚡ **行动建议**: 可落地的具体建议

**洞察卡片信息**:
- 标题: 一句话概括核心发现
- 摘要: 详细描述洞察内容
- 证据: 支撑洞察的数据依据
- 可信度: High/Medium/Low
- 可执行性: 是否可直接落地

**功能操作**:
- ✅ **选择洞察**: 点击卡片选中，用于生成选题
- 🔍 **搜索**: 输入关键词快速过滤
- 📊 **排序**: 按创建时间/标题排序
- 🎯 **筛选**: 按类型/可信度/可执行性筛选
- 🗑️ **批量删除**: 选中多个洞察后删除
- 📥 **导出Excel**: 导出所有/选中洞察

**生成时间**: 通常 30-60 秒（取决于数据量）

### 3️⃣ 选题策划 (Topics)

**功能**: 基于洞察生成内容选题

**操作步骤**:
1. 在洞察页面选择至少 1 个洞察
2. 切换到选题页面
3. 点击"生成选题"按钮
4. 等待 AI 生成（实时流式输出）
5. 查看生成的选题列表

**选题信息**:
- 标题: 选题名称
- 描述: 详细选题内容说明
- 平台: 目标发布平台（抖音/快手/小红书/视频号）
- 目标人群: 内容受众定位
- 内容形式: 视频类型（测评/对比/教程/剧情等）
- 优先级: 1-5 星级（可编辑）
- 关联洞察: 基于哪些洞察生成

**功能操作**:
- ⭐ **设置优先级**: 单个或批量设置 1-5 星
- ✅ **选择选题**: 用于生成脚本
- 🔍 **搜索**: 按标题/描述/平台搜索
- 📊 **排序**: 按优先级/创建时间/标题排序
- 🎯 **筛选**: 按平台/优先级筛选
- 🗑️ **批量删除**: 删除多个选题
- 📥 **导出Excel**: 导出选题列表

**生成数量**: 通常 8-15 个选题

**生成时间**: 通常 40-80 秒

### 4️⃣ 脚本创作 (Scripts)

**功能**: 基于选题生成 A/B 测试脚本

**操作步骤**:
1. 在选题页面选择 1 个选题
2. 切换到脚本页面
3. 点击"生成脚本"按钮
4. 等待 AI 生成（实时流式输出）
5. 查看生成的 A/B 两版本脚本

**脚本信息**:
- 版本: A版本（稳健型）/ B版本（创新型）
- 选题标题: 关联的选题名称
- 分镜数量: 通常 6-10 个分镜
- 总时长: 脚本总时长（秒）
- 创建时间

**分镜结构**:
- 时间轴: 开始-结束时间（如 0-3秒）
- 场景: 拍摄场景描述
- 文案: 口播/字幕文案
- 镜头: 拍摄镜头类型（特写/中景/远景）
- 备注: 其他拍摄要求

**功能操作**:
- 📋 **复制脚本**: 一键复制整个脚本
- 🔄 **切换版本**: A/B 版本对比查看
- 🔍 **搜索**: 按选题标题搜索
- 📊 **排序**: 按创建时间排序
- 🗑️ **删除**: 删除单个脚本
- 📥 **导出Excel**: 导出脚本列表（包含分镜详情）

**生成时间**: 通常 60-90 秒（生成2个版本）

### 5️⃣ 战略报告 (Report)

**功能**: 汇总项目成果，生成完整报告

**操作步骤**:
1. 完成前面的工作流程
2. 切换到报告页面
3. 点击"生成报告"按钮
4. 报告自动生成（约 1 秒）
5. 在线预览或导出 PDF

**报告内容**:
- **项目概况**: 基本信息、目标人群、数据来源
- **核心洞察**: 精选洞察列表（带标签）
- **选题策略**: 优先级分组的选题规划
- **脚本方案**: A/B 版本脚本详情
- **执行建议**: 落地建议和注意事项

**导出方式**:
- **在线预览**: 浏览器内查看
- **打印/PDF**: 使用浏览器打印功能（Cmd/Ctrl+P）
- **分享**: 复制 HTML 代码分享

**生成时间**: < 1 秒

### 6️⃣ 知识库 (Knowledge Base)

**功能**: 存储项目相关知识和参考资料

**操作步骤**:
1. 切换到知识库页面
2. 点击"新建知识"按钮
3. 选择知识类型：
   - 产品信息
   - 竞品分析
   - 人群画像
   - 行业知识
   - 参考案例
4. 填写标题和内容
5. 添加标签（可选）
6. 保存

**功能操作**:
- 🔍 **搜索**: 按标题/内容/标签搜索
- 📊 **排序**: 按类型/创建时间排序
- ✏️ **编辑**: 修改知识内容
- 🗑️ **删除**: 删除单条知识
- 🏷️ **标签管理**: 添加/编辑标签

**使用场景**:
- 存储产品卖点、功能参数
- 记录竞品优势、弱点
- 保存目标人群特征、痛点
- 归档行业报告、研究资料
- 收集优秀案例、爆款视频

## 🎯 功能详解

### 全局搜索

所有列表页（洞察/选题/脚本）都支持实时搜索。

**使用方法**:
1. 在页面顶部找到搜索框
2. 输入关键词
3. 列表实时过滤
4. 清空搜索框恢复完整列表

**搜索范围**:
- 洞察页: 标题、摘要、证据
- 选题页: 标题、描述、平台、内容形式
- 脚本页: 选题标题

### 数据排序

**排序维度**:
- **洞察**: 创建时间 ↑↓ / 标题 ↑↓
- **选题**: 优先级 ↑↓ / 创建时间 ↑↓ / 标题 ↑↓
- **脚本**: 创建时间 ↑↓

**使用方法**:
1. 点击排序下拉框
2. 选择排序字段
3. 点击升降序按钮切换方向

### 高级筛选

**筛选维度**:
- **平台**: 抖音/快手/小红书/视频号/其他
- **优先级**: 1-5星
- **状态**: 全部/已选/未选

**使用方法**:
1. 点击筛选按钮
2. 选择筛选条件（多选）
3. 查看筛选后的结果
4. 点击"清空筛选"恢复

**组合使用**:
搜索 + 筛选 + 排序 可以叠加使用，实现精准查找。

### 批量操作

**支持的操作**:
- 批量删除（洞察/选题/脚本）
- 批量设置优先级（选题）

**使用方法**:
1. 点击卡片左上角的复选框选中
2. 点击顶部批量操作按钮
3. 确认操作

**注意事项**:
- 批量删除操作不可撤销
- 建议先导出数据再删除

### 数据导出

**支持导出**:
- 洞察列表（Excel）
- 选题列表（Excel）
- 脚本列表（Excel，含分镜）
- 战略报告（HTML/PDF）

**导出内容**:
- **全部导出**: 导出所有数据
- **导出选中**: 仅导出选中的数据

**Excel格式**:
- 自动调整列宽
- 包含所有字段
- 支持在 Excel/WPS 中编辑

### 数据可视化

**活动趋势图**:
- 时间范围: 7天/30天/全部
- 显示指标: 洞察、选题、脚本生成数量
- 折线图展示

**平台分布图**:
- 饼图展示各平台选题占比

## ❓ 常见问题

### Q1: 上传文件后没有反应？
**A**: 检查以下几点：
1. 文件格式是否支持（Excel: .xlsx/.xls, PDF: .pdf）
2. 文件大小是否超过 10MB
3. 查看浏览器控制台是否有错误信息
4. 刷新页面后重试

### Q2: 生成洞察时报错"缺少项目数据"？
**A**: 确保：
1. 已上传至少 1 个数据文件
2. 文件已解析完成（状态显示"ready"）
3. 文件内容不为空

### Q3: 生成选题时提示"请先选择至少一个洞察"？
**A**: 需要先：
1. 切换到洞察页面
2. 点击洞察卡片选中（卡片会高亮）
3. 至少选择 1 个洞察
4. 再切换到选题页面生成

### Q4: AI 生成时间太长？
**A**: 正常情况：
- 洞察生成: 30-60秒
- 选题生成: 40-80秒
- 脚本生成: 60-90秒

如果超过 2 分钟，可能是：
- 网络不稳定
- Claude API 服务繁忙
- 数据量过大

建议：刷新页面重试，或稍后再试。

### Q5: 如何保存工作进度？
**A**: 所有数据自动保存到本地 SQLite 数据库，无需手动保存。
- 关闭浏览器后数据仍然存在
- 重启服务后数据依然保留
- 数据库文件位于 `data.db`

### Q6: 如何备份数据？
**A**: 
1. 导出 Excel 文件（洞察/选题/脚本）
2. 复制 `data.db` 文件到安全位置
3. 导出战略报告（HTML格式）

### Q7: 能否协作使用？
**A**: 当前版本为单机版，暂不支持多人协作。
- 同一时间只能一人使用
- 数据存储在本地
- 未来版本会考虑协作功能

### Q8: 支持哪些浏览器？
**A**: 推荐使用最新版本：
- ✅ Chrome 90+
- ✅ Edge 90+
- ✅ Safari 14+
- ✅ Firefox 88+

### Q9: 如何更换 Claude API Key？
**A**: 
1. 编辑项目根目录的 `.env` 文件
2. 修改 `ANTHROPIC_API_KEY` 的值
3. 重启服务 (`npm run dev`)

### Q10: 数据隐私如何保护？
**A**: 
- 所有数据存储在本地，不上传云端
- 仅在调用 Claude API 时发送必要数据
- API 通信使用 HTTPS 加密
- 建议不要上传敏感商业机密

## 💡 最佳实践

### 数据准备

**Excel 数据**:
- 第一行作为表头（列名）
- 包含数值字段（点赞数、销量、GMV）
- 包含文本字段（标题、达人、文案）
- 建议 10-50 行数据（太少洞察不够，太多生成慢）

**PDF 文档**:
- 结构清晰，分段明确
- 包含市场数据、竞品信息、人群画像
- 避免纯图片PDF（OCR识别不准）
- 建议 5-20 页

### 工作流程建议

**第一次使用**:
1. 选择行业模板（快速开始）
2. 上传 1-2 个小文件测试
3. 熟悉各个功能模块
4. 完整走一遍流程

**日常使用**:
1. 定期上传新数据（每周/每月）
2. 先筛选高优先级选题执行
3. A/B 脚本实际测试效果
4. 根据效果调整选题方向

**团队协作**:
1. 导出 Excel 分享给团队
2. 导出报告发送给客户/领导
3. 定期备份 `data.db` 数据库

### 提升效率

**使用快捷键**:
- 频繁切换页面用数字键 1-6
- 返回用 Esc

**组合功能**:
- 搜索 + 筛选 + 排序 快速定位
- 批量设置优先级节省时间
- 批量导出 Excel 留档

**合理规划**:
- 先生成足够的洞察（5-10条）
- 再一次性生成多个选题（10-15个）
- 筛选高优先级选题生成脚本

### 避免的坑

❌ **不要**:
- 上传空文件或无意义数据
- 生成过程中刷新页面
- 同时打开多个生成任务
- 批量删除前不备份

✅ **应该**:
- 上传真实、有价值的数据
- 耐心等待生成完成
- 一个任务完成后再开始下一个
- 定期导出和备份

```bash
# Claude API Key (必须)
ANTHROPIC_API_KEY=your_api_key_here

# 服务端口 (可选，默认3001)
PORT=3001

# 上传目录 (可选)
UPLOADS_DIR=./uploads

# 知识库目录 (可选)
KB_DATA_DIR=./kb-data
```
