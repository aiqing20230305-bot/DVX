### JSON控制字符问题（P2优先级）

**位置**: 
- `server/services/topic.service.ts`
- `server/services/script.service.ts`

**症状**:
```bash
jq: parse error: Invalid string: control characters from U+0000 through U+001F must be escaped at line 7, column 104
```

**影响**:
- ❌ 测试脚本中 jq 解析失败
- ✅ 实际功能正常，数据完整
- ❌ 影响工具链自动化

**对比**:
- ✅ `report.service.ts` 已在 v2.2.1 修复
- ❌ `topic.service.ts`, `script.service.ts` 未修复

**建议方案**:
参考 `server/services/report.service.ts` Line 35-42 的 `esc()` 函数：
```typescript
function esc(str: string): string {
  return str
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    // Remove control characters that cause JSON parsing issues
    .replace(/[\u0000-\u0008\u000B\u000C\u000E-\u001F\u007F-\u009F]/g, '')
}
```

在 topic 和 script 服务的响应序列化前应用相同处理。
