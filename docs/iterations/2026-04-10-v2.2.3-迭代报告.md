### 清理规则

**移除的控制字符**:
- `\u0000-\u0008`: NUL到BS
- `\u000B-\u000C`: VT和FF
- `\u000E-\u001F`: SO到US
- `\u007F-\u009F`: DEL和C1控制字符

**保留的字符**:
- `\u0009` (\t): 制表符
- `\u000A` (\n): 换行符
- `\u000D` (\r): 回车符

    code = ord(char)
    if (0x00 <= code <= 0x08) or (0x0B <= code <= 0x0C) or \
       (0x0E <= code <= 0x1F) or (0x7F <= code <= 0x9F):
